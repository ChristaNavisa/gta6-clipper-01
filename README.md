## The entry

- `VIDEO.json` — the address of the public YouTube Short for this clip.
- `main.ts` — the entrypoint: it checks that VIDEO.json names a real YouTube video address and copies it to the output directory. The video itself is what the house scores, by views.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
